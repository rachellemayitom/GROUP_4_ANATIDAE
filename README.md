**PROJECT  OVERVIEW:**

The cytochrome c oxidase subunit I (COI) gene is a mitochondrial gene widely used in biology to identify species and study how they are related. This gene is especially useful because it shows enough genetic differences to separate closely related species, while still being similar enough across groups to allow comparisons. In this activity, COI sequences from several species in the duck family (Anatidae) were analyzed to build a phylogenetic tree. An additional species outside the family was included as an outgroup to help root the tree. The resulting phylogenetic tree illustrates the evolutionary relationships and genetic similarities among the selected duck species.


_This repository archives the methodological documentation of our phylogenetic analysis utilizing NCBI and Galaxy platforms._
